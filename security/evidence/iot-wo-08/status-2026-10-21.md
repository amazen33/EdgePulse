## Qualification stop: JSpecify

grpc-api / grpc-protobuf / grpc-netty-shaded 1.84.0
  -> guava 33.6.0-android
     -> jspecify 0.3.0 (identity compile scope; runtime-reachable)

The [0.3.0 release](https://github.com/jspecify/jspecify/releases/tag/v0.3.0)
is explicitly a prerelease; its tagged README discourages use in released
libraries. It cannot receive a full maturity pass. A bounded transitive
override to the eligible stable **1.0.1**, published 2026-07-29, was trialled
and the Java gate passed again.

The remaining hard blocker is the **securityProcess** criterion. The
[upstream security-policy page](https://github.com/jspecify/jspecify/security/policy)
states "No security policy detected". Checks of repository root, `.github/`,
`docs/`, and the organisation's inherited policy returned HTTP 404. No
equivalent published disclosure/CVE-handling process was verified. The
[OpenSSF Scorecard](https://api.securityscorecards.dev/projects/github.com/jspecify/jspecify)
dated 2026-10-19 reports 5.6 overall and Security-Policy 0; the missing policy,
not the advisory score target alone, prevents a truthful verified record.

ADR-0054 requires every criterion. No verified record, build-tool
reclassification, legacy admission, waiver or exception was fabricated.
An architect decision or acceptable published supplier evidence is needed
before adoption. Other newly resolved runtime inputs also need complete
qualification; this stopped trial does not claim they all pass.

## Reachability notes for the owner checkpoint

- **TB:** an application-core image intended for future use, not an observed
  deployment. The approved findings include OS TLS/XML libraries and lz4-java.
  Its Java classpath/image contents do not prove a vulnerable call is invoked
  or absent. No JVM call-path analysis or exploitability exclusion is claimed.
  A change to TB 4.4 or a rebuilt image is outside this order's allowed path.
- **kind node:** local/CI harness only. The node image contains Kubernetes,
  containerd, etcd and supporting OS/Go packages; API/CRI/network paths and
  container privileges are meaningful attack surfaces if a cluster runs.
  Harness-only use is not an automatic ADR-0049 exemption. No custom node
  image, cluster operation or host/lab change was performed.
- **Cilium:** the three images serve the isolated kind harness. Agent/operator
  Go networking and Kubernetes interactions, and Envoy HTTP/TLS proxy paths,
  could exercise affected packages if run. Package presence alone is not
  call-path proof. No claim is made about an EdgePulse installation on Twinfra.

Work-order items 2 and 3 require owner decisions on November 12 if fixes
remain unavailable. All existing exceptions still expire on November 19;
none was edited, extended or removed in this trial.
